## 🧑‍💻 About Me

Geospatial Data Analyst with **2+ years of experience** in GIS development, remote sensing, and machine learning for spatial data. I build automated geospatial pipelines, develop ML models for satellite image classification, and create interactive web maps for urban planning and environmental monitoring.

Currently pursuing an **MS in Data Science** at Riphah International University while working as a **Geospatial Data Analyst** at Sheher Saaz Pvt Ltd in Islamabad, where I've automated data processing workflows, built 20+ interactive web maps, and support 10+ concurrent urban planning projects.

My research focuses on **Urban Heat Island dynamics** using satellite imagery and machine learning.
